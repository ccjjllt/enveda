# 070 目标定位：0.492→0.549 的缺口在 class 2

日期：2026-11-17。依据：竞赛官方 `data-description` / `Evaluation` 页原文（Kaggle MCP 实查）+ 本队实测。

## 1. 官方定义（原文要点）

- 指标：`MRR@25 = mean(1/rank_u)`，每分子**只有一个**正确结构，只算**第一个**正确猜测；第 25 名得 0.04；一个都不中得 0。
- 判等：SMILES 与答案都经 RDKit 2026.03.3 **互变异构归一化**后取 **InChIKey14 首块**比较 → **立体化学、互变异构体不罚分**（与底座 `metric_identity` 解码结果一致）。
- 测试集：约 400 分子 / 约 1,500 张谱，每分子 1–16 张（中位 3），全部 Bruker timsTOF，单同位素质量 157–1159 Da（中位 348）。
- 隐藏集加合物共 **10 种**（比可见 test 多 `[M-H2O+H]+`、`[M-2H2O+H]+`、`[M-H2O-H]-`）。
- **三类新颖度**（比例与归属全程隐藏）：
  | 类 | 定义 | 可达手段 |
  | --- | --- | --- |
  | 1 | 结构有公开参考 MS/MS 谱 | 与训练谱做相似度检索即可 |
  | 2 | 结构在 PubChem 或 COCONUT，但**没有公开谱** | 数据库检索 + 结构侧推理（预测谱/碎片/先验） |
  | 3 | 结构**不在 PubChem** | 只能 de novo 生成 |

## 2. 把 0.492 分解到三类（推断，按等比例假设）

若三类各约 133 分子：

- class 1：底座 `library_max≈1.0` → 基本 rank 1，贡献 ≈ 133/400 = **0.333**。
- class 2：需要 0.492 − 0.333 = 0.159 → 平均倒排秩 ≈ **0.48**（约 rank 2）。
- class 3：≈ 0。

若榜首 0.549 且 class 1 同为 0.333：

- 差额 0.057 全部落在 class 2 + class 3。仅靠 class 2 解释时，其平均倒排秩需从 0.48 升到 **0.65**（约 rank 1.5）；或 class 2 略升 + class 3 命中几个。

**结论：0.492→0.549 的缺口几乎全部是 class 2（同分子式异构体、无参考谱）的排序质量，外加少量 class 3。** class 1 已被库匹配吃满。

## 3. 这对"该做什么"的含义

class 2 的排序只能靠**结构 → 谱**的预测能力。本队已实测该能力的现状：

| 信号 | 未见结构上的多路 R@1 | 备注 |
| --- | --- | --- |
| timsTOF ICEBERG | 0.4395（同式组**中位 5** 个候选） | 22,825 候选实测；per-candidate 更弱 |
| 对齐头（DreaMS×Morgan） | 0.32（5 路）/ 0.131（10 路） | e180 未见天然产物实测 |
| MIST+MolForge | 0.107（MSG 修正 top-1） | 且公开源无 `mist_msg.pt` |
| 底座自身 rank-1（25 路） | ≈0.43 | 已含全部上述通道的融合 |

也就是说：**现有所有"结构→谱"预测器单独拿出来都不如底座融合后的 rank-1**，把它们以任何权重塞回去都不会提高 class 2。

要真正抬高 class 2，需要一个在**未见结构、25 路同式**上 R@1 > 0.51 的预测器——这是一次模型训练任务，不是调参任务。

## 4. 训练路径的可行性与先验

- 数据充足：`train.parquet` 约 2.5M 谱 / 275k 结构，足够训练"结构→谱"或"谱→指纹"模型。
- 算力：截至 2026-11-17，本队可用 GPU 合计约 **14.6h**（jiyujia 12.66h + zhuating 1.69h + qingyu1232 0.28h；ccjjllt 0，11-21 刷新）。T4。
- 先验偏负：同页公开记录里 7 次自训 FPNet/fe_D 替换**全部掉分**（0.418–0.443，尽管离线 Tanimoto +26.5%）；本队 044/067 也有"离线提升不迁移公榜"的前科。
- 因此训练路径的正确形态是：先在**未见结构 25 路**上验证 R@1 > 0.51，**通过再接入提交**；不通过就止损，不消耗提交额度。

## 5. 明确不做

- 不再做任何"换一个现成打分器改 rank-1"的变体（全部低于盈亏平衡 0.51，已逐个实测）。
- 不再做尾槽/生成类（算术上限 ≤ +0.0013）。
- 不把可见 test 的命中数当泛化证据（可见 test 是训练集样例，官方原文明确"will be replaced by the hidden test set during re-run"）。
