## 训练前判断

1. 在原上游按骨架整组留出的输出冻结真候选、实际误首和候选位置，再按比赛口径去别名，从同式、Morgan2 ≥ 0.60 的实际误首中找两种结构都有真实谱的对。优先选同仪器、同加合物、同原始能量单位和值，且各有两份可确认不同注射的谱。每个近骨架簇抽一对，分别记录阳离子和阴离子、真值实际名次和当前是否由强库命中。无实谱的候选保留在整线评估，只缺这项双向标注。至少留一整个独立采集来源用于确认。
2. 第一次进样做参考，另一次进样做查询，交换后再算。主指标为两种结构分别被自己的参考谱找回的比例，同时报告对角总分减交叉配对总分。比较清洗后的全谱和复现的分支峰，并对照等前体质量、同条件但错配的实测谱及仅元数据的打分。按结构簇算区间，每个化合物等权。若硬对样本不足以跨来源判断，或实测正确匹配的区间未超过错配，暂不扩大训练。简单随机负例、不同仪器或同文件多次扫描单列。
3. 若多数配对能跨采集区分，再在两份独立采集上检查 MS³ 已观察到的后继损失是否为实际误首提供可复现的区别。用前体质量、加合物、能量、谱峰数与占比相近的借用 MS³ 作错配对照。MS³ 预训练、错配 MS³、等更新步数的纯 MS² 三组最终都只输入比赛可见 MS²，不使用竞赛隐藏数据。局部编码器从候选原子环境和各峰的真实继发碎裂学习匹配，再用同一批实际错误名单训练谱–结构的双向分差。用未参与模型选择的天然产物对照原排名，逐题核算净升首、进出前五和 MRR。若提升来自错配或结构先验，则没有理由增加预训练预算。[候选目标证据](https://arxiv.org/html/2602.16507v2) · [错配和方法对照](https://arxiv.org/html/2611.28096v1)

对结构库缺失另做快速测量。冻结原候选式和各来源种子，记录通过真实预测式与起点可达的一至两次保价键编辑和常见生源连接变换。事后用真值验证最短路径只用于估计机会。需要新增多个独立来源、骨架或生源家族，才值得训练导航模型。过去 110 题的 121 万余组内唯一编辑产物，在等槽对照中只收进一道且使命中少三道。47 道负离子的 11 题索引缺失中，10 题同属 BAFG 连续链长系列。按单一家族给它们计权，无法检验生成对独立化学型的泛化。原论文仍假定公式已知，另发现深搜枝数急升。[比赛编辑回执](../progress.md) · [负离子索引核查](../../../data/references/075-negative-index-audit-2026-11-23.json) · [GEMS 原文](https://arxiv.org/html/2610.23617v1)
