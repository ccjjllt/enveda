# 实测碎裂路径的盲候选排序预实验

首轮用 MSnLib 的原生 MS²→MS³ 路径提高候选局部碎裂证据的质量。比赛端需要处理独立的 MS² 谱。先测经验路径的排序价值，现阶段无需训练神经网络。此前直接用 TargetMol 做精确谱库检索，在 110 和 101 题中都没有真结构的参考谱。以前用一张 MS² 推测峰间拓扑也未改善外部整线。因此本次测跨结构的已观测路径能否提高等候选、等碎片提案的判别。[历史 TargetMol 检索及拓扑实验](../progress.md)

最后一行合计只涉及四个不同作者原始身份，样本不足以单独衡量同式异构体跨注射的判别。负离子的 18 条定向抽查均可在原始 mzML 确认 MS³→MS² 的直接前体扫描引用。这个结果核对了导出链接的实际含义，无法估计所有链接的验证率。两种极性的身份可能重复。[Kaggle 预审计 v1](https://www.kaggle.com/code/jiyujia/enveda-075-msnlib-preflight/versions/1)

## 经验片段由来与可迁移性

```sh
python3 rounds/075-frontier/msnlib_preflight/build_evidence.py \
  --direct-proofs /private/tmp/enveda-075-msnlib-results/msnlib_preflight.json \
  --out /private/tmp/enveda-075-msnlib-branch-evidence
```

这一 CPU 作业只读取两份 TargetMol 的公开作者 MGF（合计 196,738,268 字节），验证文件摘要，复用原匹配分母。它把被实测的产物质量投影到候选图的已知位置，只保留至少两个重原子、质量窗内且唯一的一条非环单键切口假设。输出 `branch_evidence.json`、`observed_branches.jsonl.gz` 和 `descriptor_support.jsonl.gz`。区分精确图含切点与相同局部环境的片段，按极性报告原始谱级直接验证、跨原始文件、跨身份和通用骨架供给。还报告相同仪器及原始根、子能量组合中同时有至少三个文件、三个身份和两个不同非空骨架支持的键。两侧都只有少数可迁移键时，下一步应先核实提案覆盖，而非冻结大规模训练配置。不会读取比赛标注或 60 题私有面板。

## 候选和验证

- 主输入为 MSnLib v8 的两份 TargetMol 天然产物原生 MSⁿ MGF 和其 mzML 对照。先使用报告里同时通过注册结构、特征、仪器、第一段能量、实际 MS² 产物峰及同原始文件的匹配。按验证等级分别累计可确认了原生 `spectrumRef` 的路径、只有匹配导出特征的路径，以及独立原始文件的有效路径。重复子谱、同一个产物的三个 MS³ 能量及同一个原始文件只能为独立支持各贡献一个计数。
- 训练证据档是作者结构和已测分支，查询档只保留 MS²、观测前体、加合物、原始 CE 单位和值及仪器。固定散列抽取来源和近骨架簇，构建经验库前剔除全部查询身份、互变异构别名、骨架及来源文件。优先以 TargetMol 原始文件和 NIH 另一公开目录作为两层不同的留出。NIH 导出样例缺少原始文件标识，只能验证目录、骨架留出，保留这一数据限制。ETH MultiMS² 可另测跨仪器转移，其数据和元数据为 CC0，正离子 CID 和 Orbitrap HCD 需分开计量。[MSnLib 版本说明](https://zenodo.org/records/21105617) · [MultiMS² 作者发布](https://zenodo.org/records/17417089)
- 候选取同一份公开结构表，从每张查询的观察前体和加合物独立计算 ±10 ppm 窗，按固定规则优先排列 25 个不同的比赛规范化身份。名单内和名单外真值均计入分母。初步可用 MSnLib 作者 9 库结构表与其全部作者实测查询，公开标准品目录选择不等于已经复现比赛候选分布。第二轮换用已冻结的真实上游错误名单，仅对同一份名单补局部分。候选表没有覆盖的查询不手工加真值。现有 MassBank 原始公共数据可作为独立验证来源，选择按可用结构和谱的元数据预注册，不使用 60 题私有计分标签。[作者结构表和原生谱](https://zenodo.org/records/21105617)
- 在盲集内报告经过质量窗、真值与误首都入围、存在同式竞争、至少一个可迁移片段，以及两方均有实测路径约束的分母。先要求跨多个结构簇和采集来源出现支持。若只有在相同结构或同文件扫描才有足够数量，将这批用作仪器重复诊断。原始父扫描引用抽查若无法验证任何链接，用作者导出预测做探索，不能当作实测前体谱级的独立确认。

## CPU 计分

1. 把归档中每一个独立的 MS² 产物和下游 MS³ 峰连接为 `(母离子，产物，后继峰，根 CE，子 CE，原始注射)`。保留同一极性和原始能量单位。对源结构用 RDKit 枚举可解释实测产物的片段，先只允许一个非环单键切开。复用原碎片枚举及峰匹配。只在测试的氢迁移状态下得到唯一去立体化片段图时，用片段图和断裂位点环境索引，仍将其称为图假设。候选端使用同样的枚举和绝对质量误差。统计若因单键约束而大量丢失，单列质量匹配率，优先检查真实路径是否需要增加提案范围。
2. 用同一碎片图或相同的图局部环境转移后继质量损失。一个档至少有三个不同原始文件、两个非空骨架提供支持，并报告“精确片段图”和“局部环境”分别能覆盖多少候选。查询有与候选对应的母峰和测得的后继峰才记证据。在取每个候选最多 128 个提案和每谱最多 80 峰的固定预算内，对每个母峰只取一个规范后继，不让同一产物在三个扫描重复投票。
3. 三组从同一片段易发性出发。基准统一以相同质量匹配事件给分。真实路径组以源库独立结构中观察到的 `p→q` 支持率增加权重。错配组把 MS³ 树在不同源结构之间按前体和产物质量、片段式、加合物、仪器及 CE 置换。三组共用过滤、扫描、候选、质量提案和支持档位；配不到错配的候选另外报告覆盖。另用同质量、同加合物供体替换查询 MS²，保持原名单及原前体，比较在两组都能计分的谱子集。测试时不提供查询的 MS³。
4. 冻结逐候选 `candidate_id, original_rank, formula, feasible_peak_count, path_hits, control_score, true_path_score, shuffled_path_score` 和各臂排名，再由独立脚本从公开原档核对答案。先比较同式且基准质量覆盖相等的候选。整理逐题升首、丢首、进出前五、总 MRR 和按照骨架/来源重采样的区间。固定 25 槽，主结论按所有查询计。上限以受影响且真值已在名单的题为单位求 `sum(1 - 原倒数名次) / 全部题数`，以判断是否值得为本路扩训。

只有真实路径胜过等量碎片质量、错配路径和错配查询，且在独立采集来源上仍有净升首或前五，才讨论扩大实测树并用局部编码器替代查表。若路径供给或候选机会不足，优先回到真实质量窗检索与候选排序。公开 MassSpecGym 的同式等覆盖子集未发现基于质量可行性的额外收益，正适合作为本方案要补足的对照。[MassSpecGym 候选审计](https://arxiv.org/html/2611.28096v1)
