# 075 前沿计划：MS2 同分异构体判别（合并 071 结论）

日期：2026-11-19。底座：`068a` public **0.492**（`ref 58412029`）。`072/073/074` 已封闭配方、质量、召回与事后升位族；`075d`（NX 模型）在公榜跌至 **0.381** 后亦已终止。唯一剩余提分空间在 **MS2 碎片层面的同分异构体判别**。

## 原则与禁止项

- **不重训/微调比赛原生模型**：公开 7 次 FPNet 重训与本队 044/067/072a/`class2`/`075d` 均因训练骨架过拟合导致未见结构或公榜退步。
- **不将泄漏面板或单次数字当泛化**：可见 400 test 为 `train.parquet` 副本（仅作 smoke）；`072d` 只留出谱未留出化学型。所有新信号须先过 **整组化学型/骨架留出** 面板，再决定提交。
- **不新建测试文件/CI 门控**，评估均手动发起，三层状态分开记录（代码成功 → 远端完成 → 公榜提分）。

## 待验证优先方向（按性价比排序）

1. **075b 化学型整组留出仪器（先决条件）**：在 Kaggle 远端环境（RDKit `2026.03.3`，避开本机 `2026.09.2` Murcko 报错）按 Murcko 骨架或规范身份整组移出结构及全部谱，并记录训练暴露清单，形成 `S`（已见独立谱）/ `U`（无参考池内）/ `P/G`（池外）面板。
2. **零成本导出并体检管线未用信号**：在现有面板导出/评估 `068a` 已计算但被丢弃或压成布尔阈值的逐候选信号（`Engine 1 scs`、物理 `frag_new/old` 连续值、`Engine 2 frag_ad`、双神经分歧），先看错误子集上的 AUC 与配对 `ΔMRR`。
3. **外部预训练候选-谱打分器（不重训）**：
   - 首选 **官方新版 MIST（MSG `mist_msg_noaug` / `mist_msg_aug`）**：仅先覆盖支持的正离子，以推断分子式计算 4096-bit 概率指纹一致度（严禁泄漏真值公式）。
   - 次选 **ICEBERG 2.1（MSG 权重，非 NIST'23）** 对同式组 top-5 做前向熵相似度，或 **CFM-ID 4** 补位负离子。
4. **完整 MSAlign 框架（DreaMS × MoLFormer）**：仅在正确**逐谱独立编码再聚合**（修复 `083a` 原始峰序列平均缺陷）、加入 `adduct/CE` 条件与真实困难负例的前提下重新评估；不直接打包含限制条款的 MolDeBERTa。
5. **有限池外生成（MS-GPT MSG）**：仅在 MIST 检索证实增量、且能通过统一排序进入前几名时，作 50–100 个独立结构的受控补充探索。

## 止损标准

- 整组留出面板上配对 `ΔMRR ≤ 0` 或 `fix/harm < 1.5` 即停，不调参盲交。
- 任何模型/资产若发现含 NIST 及其衍生训练权重或不可复现中间产物，立即剔除。
