## 背景、目标与假设

用户要求了解现状、定位缺陷，并做一次提分 submission，长期目标为奖金与金牌。当前实测最佳为 v14/v465 public **0.456**，而非 README 旧入口的 0.432/0.446。本轮先核实账号、实际提交与榜单，再准备最有证据的单项改动；提分必须由实际提交确认。

目前最大的研究缺口是**验证流程不完整**：P/Q/NP 等本地对照跳过 ICEBERG/GLACIER，关闭 PubChem promotion 在本地持续提高、在公榜下降 0.014。不能继续仅靠这类 CPU 指标选择融合改动，也不能要求把已反复使用的几个公榜版本拟合正确，便宣称拥有独立泛化验证。

本轮假设：无真实 `[M+H]+`、可用 `[M+NH4]+` 或脱水谱构造 GLACIER 代理的 N1 分子，保留已有 ICEBERG 分数并联合重排，优于旧的二选一路径。lavinwins 版本表报告其完整路径 0.456→0.464，属于外部先例，不是本项目的预期保证。

## 冲奖主线与需继承的结论

- **先补完整流程的结构留出评估。** 固定一批规范化结构组、匹配模型排除清单、删除查询结构参考及重复谱；另外单列已见结构独立谱检索。缓存同一候选集的 base/ICE/GL/joint/最终融合分数，按有无参考、候选内外、加合物与正负离子分别报告 MRR@25、Top1、Top25召回和成对损益。NP250及P/Q已多次用于决策，只能作开发集。
- **拆开召回与排序。** 先单独评估028扩池进入 Engine1 后是否增加真实 Top25，而非只统计新增14,237个结构。扩大生成先前 C 上有收益、B 上有退化，必须测门控与正确候选被挤走的机制。
- **争取新的谱证据。** 针对无参考、同分子式、负离子及不支持加合物的失败分层，优先做完整证据路径或独立困难负例排序训练。多CE与完整生成继续作为具体失败驱动的实验，不能用不完整实现的失败将其否定。
- **公共方案是起点。** 0.464是外部历史成绩，当前第20名已0.469、第5名0.484；复制公开改动不足以说明接近获奖。需要完整验证支持的自有增量，并保留上游许可、模型训练代码与数据来源，最终以私榜与规则核验决定奖金/奖牌。
- 不从 public 总分推断隐藏类别比例；full1 的 NP 高分是训练重叠疑点，不是训练成员直接证据。不创建测试文件、自动化测试或CI门控。
