# 022 — v12：严格跨库直接参考提升

日期：2026-10-20。接手 021 结果（commit `ad2f25e`）。用户已批准构建 v12 并提交一次。对应[022进展](../progress/022-v12.md)。

## 问题

021 在 B 遮蔽（保留跨来源参考）上发现：候选若有很强的跨来源参考谱匹配而当前第一名没有，把它提到第一名可得 +0.0140（7/0）；但在 C 遮蔽（真值无参考）上同规则 −0.0046（0/5）。隐藏集里有跨来源参考的分子比例未知，本地无法判定净效应。问题是：**隐藏集上这条规则是净正还是净负？** 只能用一次实际提交回答。

## 假设

- 若隐藏集中相当比例的分子在 train 其他来源有参考谱，规则净正（预期小幅 +）。
- 若隐藏集多为无参考结构，规则会把有强参考的错误候选提前，净负。结果同时给出隐藏集参考覆盖程度的间接证据。

## 实验

v12 = v11（kernel `ccjjllt/enveda-020-e006-repro` v4）原样＋末尾一个自包含 cell，其余全部不变（PROMO_REL 仍 150、不加 MassBank538、同 16 个数据源、同镜像 v170、T4、私有、关网）：

1. 对最终 top25 每个候选，取 train 中同 InChIKey14 的参考谱（排除 `enveda-np-examples`），与查询谱做同极性贪心 cosine（0.02 Da、≥3 峰），得 q。
2. 仅当 q_j ≥ 0.8、q_top1 < 0.8、q_j − q_top1 ≥ 0.2 时把 j 提到第 1；任何异常保留 v11 输出。
3. 本地先把该 cell 独立跑在 021 B_base 输出上，必须复现 0.9709 与 7 个提升，再 push。
4. 运行 COMPLETE 且 cell 报告 ok 后只提交一次，记录提升数、ref 与 public。

## 成功标准

- public > 0.446 则保留规则，并作为 v13 底座。
- public ≤ 0.446 则规则不保留，并把结果作为「隐藏集以无参考分子为主」的证据，转向库外召回。
