# 018 — 同一批分子上分离参考库变化

日期：2026-10-18。承接[017交接](../handoff/017-corrected-panel-and-next-step.md)的实验一和实验二。007的原任务已经完成，本轮不重做。对应[进展](../progress/018-same-molecule-reference.md)。

## 问题

017在400分子面板上看到：外部参考的直接谱检索能提高跨来源 MRR，全库且移除目标结构参考时则下降。训练用的是015约5万条 stride-50 抽样参考，应用用的是251万条全库。两个面板的分子也不同，所以库大小、近邻组成和领域迁移混在一起。

## 实验

实验一只更换参考库。查询、FP+ICE 候选、v9 顺序和冻结的全数据 LR direct 模型都用015的500个分子。查询谱 hash 排除和500个目标结构的移除沿用015，不用016面板的代表谱排除。全库使用已建好的016索引；抽样条件直接使用015已保存的特征。索引上的 stride-50 子集要能复现这些已存 `direct_quality`，否则全库差异不能单独解释。

比较 MRR、Top1、逐分子得失，以及错误候选得到正谱证据的比例、最大错误 quality、truth 与最佳错误候选的 quality 差、原抽样近邻被新的最近2000条挤出的数量。NP 与 G1 分开报告。

实验二只重训 direct LR。特征、canonical 五折、样本权重和 `C=1` 不变。500分子用 OOF。017的400面板不参与训练，只用全数据模型做迁移；这400例已经参与过方法选择，不是新的盲测。

若重训后同式误抬仍明显，再加一组写死的相对特征，不扫阈值：候选相对其他同式候选的 quality 差，以及同式候选里 `direct_quality>0` 的个数。
