# 034 计划：负离子-only 分子的 ICEBERG/GLACIER 证据（step 3）

## 误差分析（可见测试 400 分子）
- 仅正 276 / 正负皆有 97 / **仅负 27（~7%）**；加合物：[M+H]+ 959, [M-H]- 193, 甲酸 31, Na 22, NH4 4, K 2, Cl 2。
- 仅负分子在现方案里完全没有模拟器证据（ICE/GL 只吃 [M+H]+/[M+Na]+；ckpt 为 MassSpecGym msg_all，负离子未训练）。
- NP250 mask B：MRR 0.953，19 个错误 top1 全部是同分子式异构体 → 同分子式判别仍是主误差，但 B 已近天花板，用处有限。
- Na/K-only 5 个分子：ICE 已覆盖 Na；甲酸-only 2 个：暂不处理。

## 方案
[M-H]- 谱整体 +2×1.007276 Da（前体与所有碎片）并改标 [M+H]+，作为代理喂 ICE 与 GLACIER；只对**完全没有正离子谱**的分子启用，避免干扰 N1（NH4/WL 代理及其 ICE complement）。

## 本地验证（train 抽样，40 分子 × 16 同分子式候选，CPU）
| | ICE MRR | GL MRR |
|---|---|---|
| 负离子代理 | 0.681 | 0.731 |
| 真 [M+H]+ 对照 | 0.852 | 0.883 |
| 随机 | 0.227 | 0.227 |
注：分子可能在 MassSpecGym 训练集内（两臂同样受益），绝对值偏乐观，但相对 lift 很大 → 值得一次 GPU。
