# 008 — 提交判断、真实候选召回与一致的残差评分

日期：2026-10-12（北京时间）。对应[实际审查](../progress/008-submission-readiness-and-recall.md)。继承007新增D、R3-50与MIST单分子结果；本轮任务是判断是否提交，而非启动新训练。

## 当前决定与背景

**暂不提交当前D、oracle扩池或MIST产物，保留v9r2。** 10月12日Kaggle MCP核实最新有效提交仍为ref57028399、public0.323。重提同一方法没有新的提分依据；一次有效新方法的验证性submission可以有价值，不要求所有研究方向都完成后才提交。

现有证据：D的有库收益伴随明确压力损失；训练与推理的缺库门控还不一致。R3五个B的0→0.64是在直接加入已知真值后取得，未完成候选发现；50例只有质量排序覆盖统计。MIST权重加载后因SAFE附加检查停机，encoder未前向，生成调用仍无谱指纹。详见配对进展，不能把这些结果当成可部署增量。

## 008-A：一次有明确边界的D2对照（最快验证路径）

假设：D在训练中让无库候选获得修正分，推理却将其置零，抵消了缺失增强的意图；对齐同一评分函数后，压力损失可能减轻。此为待证假设，不承诺修复后提分。

- 固定已重建的canonical库和原候选，复用已有forward缓存。只比较A与一个预设配置：α=0.25、τ=1，不扫描更多权重。
- 训练与推理都使用`residual = has_library * model(standardized_features)`，并对齐α、clip及候选排序规则；手动检查同一候选在训练打分与推理打分中的数值一致。
- 原D将所有无forward候选锁死为v9顺序，致使NP34/G1 21个分子无法使用谱库。D2明确允许在同一组内按`base + library residual`重排；α=0仍复现A全序，跨组优先关系先固定。排序规则不允许改变的跨组候选对，不应被当成可优化的训练目标。
- 以NP/G1研究数据训练同一模型，按canonical原分子分折；增强副本同折，标准化只用训练折。分别报告两域和有库/全无库/真值缺库/来源移除，不合成假设隐藏比例的总分。
- 保存逐候选分数、mask、fold、OOF排名和模型。若该固定对照仍出现同类明显压力损失，停止当前线性模型配置，把资源转向新证据，不继续仅改变α。

待改代码：新增`src/evidence_residual.py`和`scripts/run_008_d2.py`，从冻结的`artifacts/007-r1d/`读取特征；不要覆盖D原始结果。仅CPU小型残差训练，先实测时长再决定任何放大；不重训FPNet。

## 008-B：把oracle插入换成真实候选召回

假设：固定公开结构库内仍有当前712K池缺少的有效结构；观测质量和可推理的谱条件可以找回它们，但额外干扰会侵蚀已有正确排名。

1. 固定来源、快照、许可筛选与canonical规则，建立外部结构索引。可以复用已下载的MassBank快照；候选资产须来自独立的完整来源筛选，不能仅从待评价分子的真值SMILES提取。记录与评价谱同源的边界。
2. 查询入口只接受谱峰、前体质量、adduct、仪器与CE；使用分子式时只能来自谱预测，真值公式仅作明确的oracle诊断。不能读取`class_AB`、truth key、truth SMILES来决定候选或分配预算。
3. 对观测质量窗返回全部合格候选或预先固定的无标签截断规则，同时加入真实干扰。未知adduct不能把前体质量直接当准确中性质量；50集中5张此类谱先纠正或单列为质量不确定。
4. 分别记录完整候选库→质量窗→FP top100→最终top25的真值覆盖、MRR、候选量、已有正确答案被挤下的损失。现有R3 top100是mass-ranked，不能当FPNet shortlist。
5. 先在首批10例核对流程，再在50例报告开发结果；最终方法冻结后再用未参与规则选择的记录核查。A/B为人为分层，不用于估算隐藏类别比例；本地B只表示当前候选库外，不等于官方真正de novo类别。
6. 先做CPU召回与FP排序，确有新增覆盖后才补新候选的ICE分数，复用可兼容旧缓存。按实际新增任务数估算，首轮额外T4研究预算建议上限2小时；不为oracle插入继续花GPU。

待改代码：`src/candidate_expansion.py`（固定索引与无标签查询）、`scripts/build_008_candidate_index.py`、`scripts/evaluate_008_expansion.py`。输出新增结构来源、全候选分数与逐例增损，不只输出“找回几个真值”。最终索引须可作为Kaggle离线输入，隐藏推理不得联网查询。

## 008-C：生成仅完成正确接线，不因SAFE错误换大分子

- 当前`SAFEConverter(slicer=None).encoder(...)`禁切分又拒绝空切分，是调用错误。无切分roundtrip使用官方兼容的`allow_empty=True`，并把真值roundtrip与生成能力评价分开；它不应成为条件生成必须通过的输入。
- 保持checkpoint的SAFE表示。现有加载日志为`use_bracket_safe=False`，不能改表示绕过检查。
- 先用一个符合MIST输入契约的正谱接通subformula特征→MIST4096预测指纹，保存实际向量形状、范围与SHA。首批5个B均为负谱，不能随意换其中更大结构；50集中已有正模式候选，可按观测metadata预先选样。
- 真实谱指纹存在后，才作一次固定B=10调用，分开计请求槽位、返回、可解析、分子式匹配与去重数。记录长度配置/缺失资产；不按过滤后的幸存数循环凑B再称实际只采样B次。
- oracle公式与预测公式分开；生成召回与联合候选排序分开。检索miss不意味着联合排名等于生成排名。官方benchmark里的真值指纹排序不可作为比赛推理出口。

这条线当前不是最接近提交的路线。不因小样本运行报错就否定方法，也不再把formula-only成功当完整谱条件成功。先修CPU可查的接口，再使用已下载权重；本计划不假定旧Colab会话仍在线。

优先完成008-A的一次固定对照，同时准备008-B的无标签召回。满足以下科研证据后，制作**只有一个主要方法变化**的v10并做一次验证性提交：

- 代码、权重、候选资产已做成可离线执行的notebook，人工确认输出与实际运行成本满足比赛要求。

公开榜用于外部验证，分数可能上升或下降；保留v9r2。没有可部署新变化时不重复提交，也不因有一次探索提交机会就忽略已知方法错误。无需等扩池、谱库、负离子和生成全部研究结束。
