- 结论：人气偏差解释不了 promo 方向的反转。剩下的可能：
  1. 隐藏集来自某个特定来源，例如 CASMI 组织方挑选的天然产物。
  2. 本地只用 CPU，ICEBERG/GLACIER 被跳过，而公榜运行时有 GPU 模拟器，提升规则跟模拟器重排有交互。这一点与 promo 只在完整流程里才有收益相符，可能性最大。
  3. 公榜 0.002 量级的差异属于噪声：v13 差 0.014，不太像噪声。
